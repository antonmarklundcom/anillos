## Production follow-up

Run `pnpm exec tsx scripts/check-store-catalog.ts` in the deployed app environment and retain the sanitized codes. `db:true,catalog:false` does not justify changing a working `DATABASE_URL` host. If missing schema is confirmed, back up and use the versioned migration path after explicit production authorization. `scripts/seed-store.ts` inserts missing collection records only; it cannot repair absent columns. Never run demo seed or concepts in production.

Current fallback browsing does not establish inventory, fulfillment or payment readiness. Existing order/stock transitions and purchase guards remain authoritative. Product pages receive merchant offers only from verified purchasable products. Commercial-size mapping is deferred until the supplier's actual scale is known.
